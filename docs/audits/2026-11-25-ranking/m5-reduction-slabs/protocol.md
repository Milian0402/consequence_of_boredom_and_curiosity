# One fixed SME direct-B locality treatment

Base 69b239d6ab9b9a86425ef6874634e3a1952a7f73 with the existing Apple medium-wide opt-in enabled. The newer 24–32-row compact direct-B path preserves one packed A and all native input/output guards. Replace full-depth traversal per output tile with 64 K steps at a time, sweeping a fixed panel of 256 neighboring output columns before the next depth slab. Process both row tiles in each panel. A full B slab of 64×256 uses 64 KiB and a full C band at most 32 KiB. Retain the original ordering of FP32 FMAs for every element, spilling the FP32 ZA accumulator to C at each slab boundary and restoring it for the next one. This changes data traversal, without a packed B intermediary, prepacked persistent operands or cache-state selector. The previous failed superpanel candidate actually copied B; this one only reads the original row-major B.

The pilot is limited to 24×1088×280 and 29×2624×216, where changing operands exposed a field loss, plus the 31×3135×187 predeclared control. Two new seeds 619325179 and 1639120403. Use fresh resident and verified-locked 128 MiB logical working sets per case, matching prefaulted inputs and shared output addresses for both current shipped aliases A/B and the candidate D. A rotating batch traverses the entire pool and a hot batch repeats one slot for the same number of calls. Each method/seed completes 18 batches per mode, with six balanced mirrored label rotations and counterbalanced mode order. Full FP64 qualification on every result of every distinct slot, bitwise identity to the incumbent's ordinary FP32 product, post-batch guards/spot checks, single caller, VM residency and no page-fault assumptions.

Only an unequivocal pilot justifies consuming new unseen cases. Require rotating candidate speedup GM >=1.06, at least two of three layouts beat incumbent in each seed, hot GM >=0.985 with no hot geometry below 0.95, correct outputs and at most one geometry per mode whose A/B null exceeds ±3%. If these conditions fail, preserve the shipped source, report every result and end this design. No alternative depths, synthetic layout fits or holdout tuning.
