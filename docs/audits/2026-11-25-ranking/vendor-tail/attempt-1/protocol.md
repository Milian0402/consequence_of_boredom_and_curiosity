# Secondary vendor-assisted single-thread medium-wide study

This separately timed comparison uses production source b218beff1eaf8fd606d0934405cdc1e28ecdfe15 and the opt-in vendor-wide.patch. It follows the independently frozen stream-B study without altering that primary experiment. All secondary participants and shape groups are fixed before secondary measurement. Every implementation receives identical unpacked FP32 input values, strides, seed, ready-state and output overwrite semantics.

For each selected serial LP64 provider (oneMKL sequential, OpenBLAS 0.3.34 single-thread build), compare three whole-call interfaces. A directly matched CBLAS wrapper calls the vendor for every row. A second build calls it through COB. A third build uses COB's own AVX2/FMA kernel for an eligible final one to four rows. Only a prior CPU/ISA check permits this tail. On a CPU without AVX2/FMA the public route issues one call covering every row. The engine covers 48–256 rows, 512–4096 columns with N≥4M, depth 96–768 and M×K≤98304. Arbitrary legal leading dimensions are supported. Invalid or overlapping output falls back. Provider identity and one-thread qualification run in the same private ELF namespace used for measurement, separately for each implementation.

The panel keeps the original two repeats, five fresh transfer shapes and one out-of-range control from stream-B. Four additional layouts were frozen to exercise tails of exactly one, two, three, and four rows. Report results for the five originals and four additional layouts independently. The 37-row original holdout intentionally bypasses the new route. Label direct and vendor-assisted results separately from standalone COB and stream-B.

One pinned native Linux CPU runs each worker, with two seeds (348271759, 710438957), three counterbalanced rounds per seed, FP64 reference and full-output 0.002 tolerance, cancellation/scaling stress on all shapes, checked input immutability and output guards. Report per-shape ratios, cohort geometric means and round-level wins. Attribute tail improvement only if it beats its matched full-call public build and matched direct CBLAS. Report comparisons with standalone COB, stream-B and the fastest eligible independent comparator, including ties or losses. No performance promotion threshold or winner-dependent shape selection. Missing required comparator, trace, round or validation data makes the secondary evidence incomplete.
