# Can three FP16 hardware products compete on Apple M5 Max?

Freeze six layouts (M, N, K) before receiving the Apple candidate: 512³, 1024³, 2048³, 4096³, cropped 1471×1973×1559 and cropped 187×2711×433. Square input and output strides equal their widths. For crops use independent A/B/C row strides K+11, N+19, N+23 and respective origins at 3, 5 and 7 elements plus one parent row. Two independent seeds per case: 204716321 and 745821359. Methods are direct single-thread Accelerate, released standalone COB, MaxMulSK (compact native for squares, full conversion inside the call for cropped views), the elastic Arm KleidiAI FP32 kernel with packing, the new raw FP16 hardware product, and the compensated three-product candidate. OpenBLAS supplies the independent single-thread FP64 reference. This is a finite feasibility comparison.

Time six balanced warm complete calls per method/shape/seed for ordinary centered FP32 data. Charge allocation, FP32-to-FP16 packing, range handling, compute and correction. Precede timings by one setup call per method. Check all outputs outside the timing window against FP64 plus scalar reference dots, padding around C, and input hashes. Also validate one positive case and one paired signed-cancellation case per shape. Count both violations of the project 0.002 absolute tolerance and maximum/RMS relative to native FP32 error. A lower-precision or refused route cannot qualify for FP32 ranking. Admit a candidate only if every fixture is finite, within 0.002 and has max/RMS error within 2x the direct COB FP32 control with a small allowance for one binary32 rounding at the result scale. A 1.5× or 2× speedup is measured against the fastest qualified full-call FP32 rival on each layout. Raw FP16 is a diagnostic; an arithmetic-throughput observation measures this implemented schedule, not a CPU-wide impossibility result. Retain failed controls and report actual calls, all tested inputs, hardware, and any omitted competitors.

For reproducibility, the two observed error limits are 2 × direct COB maximum absolute error + 2⁻²³ × maximum absolute reference, and 2 × direct COB RMS error + 2⁻²³ × reference RMS. Evaluate each per fixture before a layout can count. The absolute 0.002 limit is a separate gate. A full timed layout has 12 observations per method. Report the paired median relative speed and how many paired calls favor the candidate.
