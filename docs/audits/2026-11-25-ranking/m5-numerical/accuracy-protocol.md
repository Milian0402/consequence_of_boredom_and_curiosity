# Frozen numeric qualification

Use default round-to-nearest-even, finite FP32 input, row-major ordinary public GEMM, unit scale and zero beta. Numerical reference is a sequential double-precision sum in increasing p of FP32 inputs converted to double; build the oracle without fast-math or reassociation. For every output, determine nearest float R by conversion of that reference to FP32, and its quantization gap q. If q <= 0.002, require finite candidate and absolute error <= 0.002; if q > 0.002, require exactly R. Count both categories and all failures. Check every guard, A/B preservation and separate-copy agreement. For exact zero, +0 and -0 are equally close; the strict bit check only applies where q > 0.002. Finite reference magnitude and ordinary finite output are required for every fixture. Compare the same data against b218bef with the same criteria and publish all raw results.

Shared A/B and equivalent independent copies of both operands: (49,35,39), (64,25,29), (57,19,41), (63,31,47); common padded leading dimension k+3. Test both bounded random A and the previous scaled A pattern. Reproduce historic 64x25x29 value using seed 40096813 and lda=ldb=32 and ldc=31. Old random, near cancellation, and reciprocal mixed-exponent inputs are included. Additional nonreciprocal scales use independent A and B and a shared 6-bit exponent distribution, with absolute logical values <=256. Test exact dyadic adversarial fixtures: many large positive terms followed by their negatives, each with magnitude <=8192, and a 2^-13 or 2^-12 residual placed between them; also FP32 quantization gap tests at signed 2^20 with a 1/32 offset or 1/16 midpoint, alternately nearest-even down/up. Comparable random/guard/overlap fixtures and all 16,896 previous dimensions run unchanged. Validate CMake-built ordinary public entry, explicit route counts, aligned exclusions, and production CTest. No testing of NaN/Inf operands or exceptional value propagation is claimed. Final acceptance requires zero candidate avoidable error, zero incorrectly rounded unavoidable cases, zero non-finite and zero canary changes/parity mismatches on this corpus. Count all original fixed-limit failures separately.
