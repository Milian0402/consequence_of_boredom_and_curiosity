# Public install numerical comparison

Both ordinary installed CMake libraries receive independently generated, identical FP32 inputs in each fixture. Six representative compact/padded/edge geometries, three seeds, normalized random, alternating cancellation, reciprocal scales by K index (2^-10 through 2^10), and three positive correlated cases made by setting B[p,j] to A[j%M,p] with A and B each at multipliers 4, 16 or 32. For every output store the double result, its nearest FP32 value, the error of ON and OFF, logical input and C-padding integrity. Report violations of the historical absolute 0.002 gate, unavoidable violations due to nearest FP32, violations that a nearest FP32 would avoid, and ones introduced or removed by the ON route. This is a characterization of finite FP32 arithmetic. Report significant newly introduced threshold failures explicitly before integration.
