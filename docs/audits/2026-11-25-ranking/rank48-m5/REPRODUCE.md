The evidence table is in README.md. From this directory, run `python3 audit.py raw` and compare the JSON to analysis.json. The offline audit uses the Python standard library.

To repeat the measurement on an Apple Silicon Mac, install CMake, Python 3.12 or later, and the Xcode command-line tools. Use a public checkout of the benchmark repository with the history of commit `af33d7d4266ff27525839b6ed644929792720c76`. From this directory, set `BENCH_REPO` to the checkout and run `bash run.sh replay` with the machine available for measurement. The destination must be new. The script reconstructs and verifies all 30 files of the public COB release `b218beff1eaf8fd606d0934405cdc1e28ecdfe15` from the published recipes, compiles the unmodified published schedules and the Apple measurement worker in a temporary directory, and copies the new evidence to `replay`. The SHA-256 values in identities.json describe the recorded run. Linker UUIDs, compiler versions and library versions can change binary hashes across builds.
