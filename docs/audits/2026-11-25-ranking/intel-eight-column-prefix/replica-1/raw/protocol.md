# Computing an eight-column prefix before sequential oneMKL

The registered subject is `host-prefix8`. On an Intel processor with AVX2 and FMA, it computes the first eight columns with a standalone four-row-by-eight-column kernel and sends the remaining N−8 columns to the same pinned sequential oneMKL SGEMM. The controls are the raw oneMKL CBLAS adapter (`mkl`), a matched forwarding wrapper (`host-forward`), and a split control that sends both the first eight columns and the remaining N−8 to oneMKL (`host-split8`). Each public call overwrites the complete FP32 output. The trailing vendor call receives the original leading dimensions with B and C advanced by eight floats. These three wrappers reuse the resolved vendor function, with no retained plan or matrix packing between calls. All three are vendor-assisted methods.
