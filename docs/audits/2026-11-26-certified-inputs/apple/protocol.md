# Exact signed-byte pilot on Apple M5 Max

The experimental complete-call method accepts finite integral FP32 entries in the inclusive interval [-63,63] with 1 <= k <= 4096. It packs and validates inside the call, uses signed SME INT8 SMOPA, and writes FP32 output. A failed admission or unavailable ISA uses the same explicitly single-thread Accelerate SGEMM as the direct control. Compare with standalone COB as a separate control. No packing or plan is retained. This measurement stands apart from Linux BF16.

Use UCI Optical Digits test-by-training dot products (1797 × 3823 × 64), an ordinary independently generated centered full-mantissa FP32 matrix at the same dimensions (declines), and one synthetic full-range signed integer 1024 cube to test long reduction. The UCI ordering is that of the published training and test sets. Load counts as FP32 before timing, as all three methods implement the ordinary FP32 input ABI. Numerical regressions separately cover late refusals and all square/tile/depth tails. No CPU affinity is available on this Mac.

Nine warm complete calls per method per shape, one untimed warm-up, balanced rotations with alternate directions. Report all matched ratios against both controls. Test every integer result with an independently exact reference and every fallback result against the same Accelerate output, including C padding and unchanged input checks. Do not extend the shape set to recover a loss.

Prospective supplement before any timing: the corpus owner provided a second actual task, linear dots of 1,797 writer-independent binary 32×32 digit images against 1,934 training images. This adds one 1797×1934×1024 layout, with no record replication or K padding. For binary data also time a purpose-built FP32-input, validation-and-packing-included bitset AND/popcount implementation; qualify it on the same full exact output. The original three-method timings and the binary-only four-method observations use rotating order; on the binary case use twelve balanced observations per method so all four positions balance.
