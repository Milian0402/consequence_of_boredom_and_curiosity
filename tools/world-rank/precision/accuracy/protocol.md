# Accuracy contract for decomposed BF16 SGEMM

The subject overwrites FP32 C with the row-major, no-transpose product of binary32 inputs A and B. Standalone input, compiler and implementation identities accompany each result. Input families, seeds (0x51D9A47B and 0xA37C096D), generation code and per-matrix SHA-256 digests are frozen before candidate output is observed. The fixtures cover different operands and demonstrate failure modes. The seeds do not represent independent hardware or probability samples.

The software control rounds each high component to BF16 using nearest-even, widens it to binary32 and subtracts it from the residual in binary32 before taking the next component. BF16 gradual underflow is preserved in this software model. Intel instructions and library kernels may flush differently or use grouped dot accumulations. Report raw high×high, the 3-product upper triangle (01,10,00), the 6 products (02,11,20,01,10,00), and all 9 (22,12,21,02,11,20,01,10,00). Each model term is a separate dot with a binary32 FMA at each step, with partials added in the listed order. The direct binary32 control applies the same sequential FMA to the original inputs. A real 3-call widened-K implementation of the six products has its own native row; a different reduction order can change bits. Software controls are unrestricted arithmetic comparisons. The actual wrapper may return an ordinary FP32 fallback on a whole case. Count its route, term calls and reason separately. A fallback pass cannot qualify a BF16 fast path. Real SGEMM arithmetic need not bit-match sequential FMA or a correctly rounded exact dot.

For every finite-input output, form the *exact* dot P and S = Σ|aₗbₗ| by adding integer products in units of 2^-298. Round P once to binary32 with nearest-even, including gradual underflow and overflow. Record exact target classification, absolute error against P, correctly-rounded ULP distance (signed zeros coalesced), zero loss, sign reversals, >1% relative error for nonzero P, >0.002 absolute errors, and how often even the best binary32 output misses 0.002. Inherited checks reflect the HK experiment's exact-dyadic, reciprocal-depth, cancellation and scale witnesses. A finite-result failure or IEEE class mismatch is an explicit failure. A finite computed zero for an exactly tiny nonzero P is interpreted relative to its correctly rounded representation. Compare NaN as a class, and infinity including sign. NaN payload and the sign of an exact mathematical zero are outside this target.

For finite, original-normal inputs compare the observed componentwise forward error rho = |C−P|/S with gamma_K = K/(2^24−K), the usual sequential FP32 fused-dot envelope under nearest rounding, no overflow or underflow, and no exceptional arithmetic. The exact-integer comparison is |C−P|·(2^24−K) > K·S. For S=0 only zero error passes. rho equals the least maximum relative perturbation of independent scalar *product terms* explaining this one dot; it does not certify a consistent perturbation of the shared matrices A and B. For well-conditioned outputs |P|≥S/4, also count errors exceeding two ULPs. Additionally report the maximum dot-relative error and cases where P=0. Near-cancellation can make relative error or ULP distance large while rho stays small. The gamma_K count is a diagnostic yardstick on range cases; no conventional no-underflow/overflow theorem is assumed there.

For interpretability, report both exact comparison and in-range screening separately. A tested method clears the ordinary-fixture envelope only if every output in every normal family for both seeds matches its reference class and satisfies the gamma_K criterion. Exact representable HK dyadics and correct class behavior on exceptional fixtures receive separate verdicts. Zero-depth overwrite must set every C element to zero. Record boundary cases regardless of success. There is no wall-time measurement, no promotion by random absolute error, and no universal FP32-accuracy conclusion. Native checks use independent padded strides and nonzero parent offsets, protect A/B parents read-only and verify untouched C storage outside the logical output.
