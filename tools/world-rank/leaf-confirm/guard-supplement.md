# Post-score validation of the first HK15 magnitude guard

The ranked field and its preregistered scoring rules use the released f322a9a standalone method. A discovery on different data showed large relative error from its HK15 linear combinations for bounded positive dyadic inputs. The post-score supplement measures the standalone source with the exact trial guard patch SHA-256 eba736a36d44e2a3ddab2b849d2373bc61061bcb1c0931a33bae91f8b2803c6f. It uses the same native release compiler flags and public installed archive linkage. This guard is experimental.

On each of the three repeat and three fresh layouts, use both registered random seeds and three same-seed rounds. A new process runs one complete warm-up followed by one complete timed multiply. Within a pair the order alternates with layout index and round, and reverses for the second seed. A cohort's effect is the equal-weight geometric mean of per-layout median unguarded/guarded wall ratios; also retain the six pairwise ratios, medians by seed and caller CPU durations. All guarded and unguarded calls bind to identical logical input digests, meet the full FP64 error limit 0.002, verify parent padding, CPU and thread count, and must have identical logical output SHA-256 in each timed pair. Any failed comparison stays visible and removes that layout from a complete cohort result. No guard speed threshold was selected. This supplement occurs only after the last original ranked sample.

A separate post-score audit exercises 19 exactly representable dyadic patterns on the prior discovery-independent 1931 × 2903 × 2881 geometry. Dimensions, pattern, clipping, sign reversals, false zeros, nonfinites and full-output error counts are retained for each installed implementation. Direct serial OpenBLAS supplies an independent classical control. Its diagnostic wall times do not enter the ranked field or the guard timing ratios.
