# Cropped SGEMM views on one x86 core

The question is whether the two earlier one-shot leads for installed COB with streamed B panels persist when A, B and C are cropped from independent dense row-major parents. Each geometry has two layouts with identical numerical inputs. The aligned companion reproduces a shared padding and page-aligned matrix bases. The cropped layout uses three different physical row strides and three independent row and column origins. Their 64-byte address residues are distinct and nonzero. In both layouts the rest of the parent is preserved. The experiment measures the combined effect of changing strides and origins.

The registered repeats are the two earlier direct-library wins (108×1728×320, 137×2179×347) and one earlier loss (49×2861×157). Three new odd geometries (43×2291×137, 87×2809×239, 127×1847×281) cover both sides of the packed-A cutoff. Numerical output dimensions use M×N×K. Panel SHA-256 is ab9115f17a698938d14e3fb0010f05e450b214eca8876d7fd6d59e2323b17c80.

All release builds use the same generic x86-64 GCC flags as the earlier installed release. The primary method is the ordinary public function from the installed a30d71f CMake archive with stream B enabled. The matched default omits this option. The secondary packed-A method adds only the previously frozen frontier patch and switch. No selected performance result or vendor-dependent dispatch is used in these builds. Compare the direct Ubuntu OpenBLAS, oneMKL normal, oneMKL sequential direct/JIT-capable interface, and single-thread AOCL 6.0 peers previously used for release acceptance. Every public entry is linked into an ordinary executable. Companion witnesses verify its actual route and forwarded parameters for all twelve layouts.

Four full FP64 fixtures (random seeds 73194513 and 38641729, cancellation and scaled) must pass the absolute 0.002 threshold with finite values and all C guards intact. A/B mappings are read-only for every product. Sentinel data surrounds each logical submatrix within its parent, the mappings have inaccessible outside pages, and warm timed batches also pass full output verification. Every process runs pinned to the same logical CPU and checks the OS task count. Each combination records a first complete SGEMM and six warm batches of 16 complete calls in fresh worker processes. Order in the second three-round block reverses the corresponding first-block order; seeds alternate by block. Direct library initialization is outside the clock. First-call values include SGEMM lazy setup and are reported separately.

For each geometry and layout report all medians, six matched peer/production ratios, and the fastest peer by median among the four independent one-shot interfaces. Report separately the aligned and cropped winner, the matched crop/align effect for each method, and opt-in/default. A prior headline win transfers on this host only when both the aligned companion and the cropped layout beat the fastest independent by median, with at least 4/6 matched pairs in each. If an aligned win fails to reproduce, the crop result remains measurable but the reversal cannot be attributed to cropping. Fresh results stand separately, as do the secondary packed-A comparisons. No method can rank on a layout with missing gates. Conclusions are limited to the reported host and measured interfaces.
