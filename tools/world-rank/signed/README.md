# Signed Winograd native comparison

The primary comparison uses the ordinary row-major FP32 COB entry, compiled from the same patched release with signed terminal updates disabled and enabled. It times each complete matrix multiplication on one pinned CPU. The published panel fixes two prior layouts, two new odd layouts and one new near-square control. The primary target is the Intel Xeon 6975P-C with sequential oneMKL. Other hosted processors and the OpenBLAS and ArmPL runs provide transfer measurements. [Original panel and decision rule](frozen/protocol.md) · [Public preregistration](https://github.com/Milian0402/consequence_of_boredom_and_curiosity/tree/a9dd7149bb6f14915bc73843562a1c03e184fc1b/docs/audits/2026-11-25-ranking/signed-winograd)

Separate traced binaries check the destinations, signs and strides of the 49 core calls, including seven positive and seven negative updates when enabled, and check all applicable edge calls. Worker processes measure the ordinary release executable and record its peak absolute FP64 error, signed error range, inputs, guards, first-call latency and six paired warm timings on every layout. Independent rows cover the native direct provider, pinned OpenBLAS, BLASFEO and applicable AOCL, oneMKL JIT, oneDNN and FastMMW methods. The oneMKL JIT label measures its direct-call interface, which routes these large products through its ordinary SGEMM fallback. The tables identify which methods qualified on each layout and distinguish oneDNN's retained-plan measurements from one-shot calls.

On native Linux with the benchmark vendors built as in the workflow, run `bash tools/world-rank/run.sh OUTPUT_DIR VENDOR_DIR`. The `signed-leaves` result directory contains the original worker records, route checks, build evidence, method eligibility, paired comparisons and the observed CPU model.
