# Explicit Intel oneMKL LP64 SGEMM handles

Both rank plugins link the same Intel LP64, sequential threading and core DSOs as the direct comparator. The build verifies the resolved paths and hashes, the exact lifecycle imports, and the absence of direct SGEMM or alternate threaded BLAS. Every operation uses row-major untransposed FP32 inputs, alpha one, beta zero, and the three supplied leading dimensions.

The one-shot entry creates the handle, retrieves and invokes its callable on the caller's operands, and destroys it within every multiply. The prepared entry offers `rank_handle_prepare(m,n,k,lda,ldb,ldc)` for setup ahead of measurement. Its thread-local plan stores the six shape fields and a handle and callable. A call with the same fields reuses them with the actual new operand pointers. A new key creates a replacement and destroys the old handle. The single benchmark thread releases its retained plan when its plugin unloads. Neither mode pre-packs or retains operands.

The preparation return and `rank_handle_last_status()` distinguish a generated kernel (0) and a callable fallback (1). A negative value records an invalid or failed operation. Unavailable kernels and failed handle creation cannot produce successful numerical qualification. The serial rank worker calls the status getter outside the timed operation.

Build with `bash build.sh VENDOR_DIR BUILD_DIR`, then run `taskset -c CPU python3 routes.py PANEL.csv VENDOR_DIR BUILD_DIR OUT`. The vendor directory must provide `mkl-prefix.txt` from the pinned comparator installation. Set `MKL_NUM_THREADS=1 MKL_DYNAMIC=FALSE OMP_NUM_THREADS=1`. Each diagnostic process checks the ordinary and separately instrumented plugins against independent double-precision products. Read-only input parents, guarded output storage, new operand addresses, individual key changes and injected failures exercise the lifecycle. Trace-only linker wrappers observe actual setup calls and return a trampoline that checks the actual caller pointers before forwarding to the resolved oneMKL function. Separate uninstrumented plan-only workers record time for create, lookup and destruction and adjacent clock overhead on each layout.
